# 数据库版 Dornheim RMS

新入口：`run_rms_Dornheim_db_v2.py`，不修改原 run_rms_Dornheim.py 或物理引擎。

从 XRTS 根目录运行：

```powershell
& .\RTS_calculating\.venv\Scripts\python.exe .\RTS_calculating\run_rms_Dornheim_db_v2.py
```

加 `--show` 可弹出窗口；默认保存 PNG，适合命令行和批处理。输入默认使用脚本同目录的镜像后 exp_data.txt、sif_data.txt，数据库路径相对脚本定位，工作目录不影响默认路径。

处理链沿用同学 PDF 第 9-10 页及本地参考代码：截断实验/SIF 负噪声、重复 x 取平均、线性插值、SIF 面积归一化、S_tot 与 SIF 卷积、在 [-35,-10] eV 内面积归一化、逐点平方差均值开方。dE=0.1 eV，PAD=20 eV。数据库谱只将能量/谱值成对排序，不额外镜像。

扫描真实数据库网格：40 度，rho=5,10,...,50 g/cm3，Te=5,10,...,50 eV，100 条已计算谱。电子密度直接读取 NPZ n_e，不将质量密度当电子密度，也不生成不存在的 45x45 参数谱。零填充/奇点跳过记录不参与。

## 输出

默认目录 `rms_db_v2_results/`：

- `rms_Dornheim_db_v2.png`：RMS 填色等高线、黑色等高线、最小值星标，以及最佳拟合与实验双图。
- `rms_scan.csv`：每条真实算例的 rho、Te、ne、RMS 和文件名。
- `rms_grid.npz`：Te_eV、ne_m3 和 RMS 矩阵，矩阵形状为 (密度数, 温度数)。
- `best_fit.txt`：能量位移、归一化实验、卷积后归一化理论，三列。
- `summary.json`：参数、最佳点、数据库物理配置及限制。

首次完整运行：188 个实验拟合点；最优算例 case_r05_T10_th040.npz，Te=10 eV，rho=5 g/cm3，ne=6.682357703152599e29 m^-3，RMS=0.017470239206752575。

## 解释限制

1. 数据库 E0=5.0 keV，实验 E0=2.96 keV，条件不一致；弹性宽度和方法也以数据库元数据为准。当前结果用于接通流程，不能称为同条件论文复现。
2. 最优点在密度下边界，尚不能宣称获得闭合的全局最优区间。
3. 为对齐参考程序，保留 `convolve(..., mode='same')*dE` 在 [-55,10) eV 非对称网格上的原始索引。参考代码将该网格也用于 SIF，数组中点不是零能量，存在卷积零延迟偏移；本版没有悄悄纠正。若需物理正确的零延迟卷积，应另行明确修改并重算，而不能把兼容结果当作已修正结果。

验证：最佳算例另外逐行按参考代码的 interp1d/convolve/归一化/RMS 独立复算，与输出一致；检查 10x10 网格完整、所有 RMS 有限、最小值一致，以及整理后的 db_v1 读取可用。
