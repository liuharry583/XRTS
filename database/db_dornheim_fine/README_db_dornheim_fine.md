# db_dornheim_fine — Dornheim 专用细网格 RPA 理论库

构建：2026-10-26，draft3 新版引擎（PhysicsConfig 接口），96 秒 / 1209 case。
动机：db_v2 是通用库（E0=5 keV、步长 5、±400 eV/600 点），做 Dornheim 拟合时条件不对齐、
低 ne 缺失、Te 与能量采样都太粗。本库把拟合条件全部固定并加密网格。

## 固定条件（与 wsb 交付的 RMS 反演设定逐项一致）
- E0 = 2.96 keV，θ = 40°，纯 Be（ZA=4，Zf=2.0）
- NU_MODE=const、NU_FRAC=0（ν=0），SII_MODE=arkhipov，弹性宽 18 eV，method=maxwell

## 网格
- Te = 1..31 eV，步长 1（31 点）
- ne = 1×10²⁹ .. 2×10³⁰ m⁻³，步长 5×10²⁸（39 点）；manifest 附 Be/Zf=2 等效质量密度
- 能量窗 −100..+100 eV，2000 点，步长 ≈0.100 eV（原生密采样，非插值）
- 每 case 存 E_eV（降序）、S_free、S_tot、n_e、k、meta_json

## 两点须知
1. **ne ≥ 1.85×10³⁰ 的 124 个 case 是 1998 点**：引擎为避开 ω=0 处 FDT 的 0/0，
   剔除 |ω| ≤ 1e-3·ωp 的点；高密度下该带宽（±0.053 eV）盖住中心 2 个网格点，
   在 E≈0 留下一个 0.30 eV 间隔。位于弹性峰内部、远离拟合窗，插值/卷积不受影响；
   这是引擎固有行为（旧库同样如此），非建库错误。
2. **ν=0 时 RMS 谷底不可作物理结论（重要）**：Maxwell 分支在 ν=0 时 plasmon 峰是
   FWHM≈0.01 eV 的针尖，远细于任何实用采样步长（0.08–0.1 eV）；其采样面积随
   (Te, ne) 与网格对齐情况混沌涨落（实测相邻 Te 间可差 20–30 倍），并经 SIF 卷积
   的远尾（数字化 SIF 在 −39…−14 eV 仍有 ~3–5% 相对底噪）传进拟合窗。
   已验证：(a) 换理论谱采样 nw，RMS 凹陷的位置整体搬家；(b) 给 ν=0.05·ωp 后
   RMS(Te) 变平滑（同一 ne 下 10.4–11.4 eV 内 RMS≈0.0263 几乎不变）；
   (c) 把理论谱的针尖区（−52…−47 eV）挖除后，原"凹陷点"与相邻点的 RMS
   变得完全相同（0.03623）。故本库重扫的表观最小值（Te=12 eV、
   ne=1.6×10³⁰ m⁻³、RMS=0.0176；全场中位 0.0357）只是又一次采样抽奖，
   先前 45×45 扫描的 (10.89 eV, 0.0175) 同理。继续做反演前应先处理针尖：
   引入物理碰撞展宽（组内需定 ν 的约定），或对针尖做面积守恒处理；
   单纯加密 (Te, ne) 或能量网格解决不了。
